## 原生 IP 和家宽 IP，差的不只是一个标签

原生 IP 的定义是 IP 注册地和服务器所在国一致。机房向当地注册局申请到的 IP 段，挂在自己的 ASN 下，IP 数据库查出来是澳大利亚，这就叫澳洲原生 IP。它解决的是“地区归属”问题。

家宽 IP 解决的是“用户类型”问题。IP 数据库会把地址归类成住宅宽带、商业宽带或数据中心。TikTok 的风控系统看这个分类，也看 IP 的历史滥用记录。一个 IP 注册在澳洲但被标成数据中心，和一个 IP 被标成某 ISP 的家庭宽带，在平台眼里的可信度不一样。

WePC 四条线的标注正好对应这三个层次：

- AU Basic 和 AU Pro 写的是“澳洲原生 IP”，归属地没问题，但未承诺家宽属性。
- EXETEL 家宽写的是“EXETEL 家宽 IPv4”，上游是澳洲本地 ISP EXETEL，数据库里更接近住宅宽带。
- 悉尼直播线路和墨尔本 TikTok 专用写的是“静态家宽 IPv4”，IP 固定不变，属性偏家宽。

digvps 上有一条 2024 年的用户简评，说墨尔本这条线“机房属性全家宽，我极度怀疑这是车库云老板自己家的 IP”。这是一句调侃，但说明在第三方数据库里，这条线的家宽属性是能查到的。2026 年 3 月同一页面又有人补了一句“时隔两年，IP 质量依然惊艳”。

所以最便宜的 AU Basic 适合发视频、起号、跑脚本，但真开直播推流，还是选带“家宽”标注的那三条。
